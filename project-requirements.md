# Semester Team Project
## Multi-Cloud Cloud-Native Application Project
### Objective
Design, implement, deploy, and evaluate a cloud-native application using services from at
least two major cloud providers.
Students work in teams of 2-4.

## Suggested Application Domains
### Teams may choose one of:
1. Higher Education
2. Healthcare
3. Smart City Applications
4. Research Computing
5. Travel and Hospitality
6. E-Commerce
7. Finance
8. Sustainability

## Required Technical Components
Students must justify selection.

### Front-End Layer

#### Examples:
1. React
2. Angular
3. Vue
4. Next.js
#### Hosted on:
1. Azure Static Web Apps
2. AWS Amplify
3. Cloud Run
4. Equivalent platform

### Application Tier
#### Must use:
1. Containers and Docker
#### Deployment options:
1. Azure Kubernetes Service AKS
2. Amazon Elastic Kubernetes Service EKS
3. Google Kubernetes Engine GKE

### Data Tier
#### One of:
1. Relational database
2. NoSQL database

### CI/CD
GitHub Actions required.

### Infrastructure as Code
Terraform required

### Monitoring
At least one observability dashboard required.

### Security
Must demonstrate:
1. Identity management
2. access control
3. secrets management

### Multi-Cloud Requirement
At least two cloud providers must be used.

## Project Milestones
### Milestone 1 (Week 6)
#### Project Proposal (5%)
#### Deliverables:
1. Problem definition
2. Architecture Diagram
3. Technology Services
4. Cloud provider selection rationale

### Milestone 2 (Week 10)
#### Prototype Review (10%)
#### Deliverables:
1. Initial Deployment
2. CI/CD pipeline
3. Basic functionality

### Milestone 3 (Week 12)
#### Technical Review (10%)
#### Deliverables
1. Functional Implementation
2. Monitoring
3. Security Review
4. Documentation

### Final Presentation (Week 14)
#### Final Demonstration (75%)
#### Deliverables:
1. Live system demonstration
2. Architecture presentation
3. Cost analysis
4. AI-usage reflection
5. Lessons learned
